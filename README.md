## ⚡ Что можно изучить в проектах

- **Структуры данных и контейнеры:** работа с памятью, итераторами, принцип хранения данных  
- **Архитектура систем:** микросервисы, взаимодействие сервисов, хранение и поиск данных  
- **Автоматизация:** тестирование API, UI, написание автотестов, интеграция с CI/CD  
- **Интерактивность:** Telegram-боты, работа с пользовательским вводом, автоматизация задач  
- **Docker & DevOps:** разворачивание проектов через Docker Compose  

Все проекты написаны с соблюдением современных стандартов (C++17, Python 3.x) и могут быть запущены локально или изучены через исходный код.
